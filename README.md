# Комбинаторика с анимациями

Интерактивный сайт по школьной комбинаторике (10 класс, раздел «Элементы комбинаторики»):
правила сложения и умножения, перестановки, размещения, сочетания — без повторений и с повторениями.

- теория и вывод каждой формулы;
- интерактивные анимации: кодовый замок, дерево выбора, пьедестал, «склеивание» наборов, треугольник Паскаля, лифт, анаграммы, шарики и перегородки;
- задачи с проверкой ответа и решениями;
- тренажёр со случайными задачами и помощник «Какую формулу взять?».

Сайт статический: HTML + CSS + JS, KaTeX и шрифты лежат в `vendor/`, интернет-библиотеки не нужны.
Чтобы открыть локально, достаточно запустить любой статический сервер в этой папке.
